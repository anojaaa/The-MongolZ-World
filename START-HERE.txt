THE MONGOLZ WORLD - COMPLETE PROJECT

Open on Windows:
1. Extract this ZIP.
2. In VS Code, use File > Open Folder and choose The-MongolZ-World
   (the folder containing package.json).
3. Open Terminal > New Terminal and run:
   npm.cmd install
4. After it finishes, run:
   npm.cmd run dev
5. Open the Local URL shown in the terminal, usually http://localhost:8443/.
   Keep the terminal open while you work. Stop it with Ctrl+C.

Publish to your existing GitHub repository:
1. Copy the extracted project contents into your existing local repository
   folder, merging folders and replacing matching files. Keep that existing
   repository folder so your GitHub connection and history are preserved.
2. On GitHub, open Settings > Pages > Build and deployment.
   Set Source to GitHub Actions.
3. In your existing repository terminal, commit and push the changes:
   git add src/App.tsx vite.config.ts .github/workflows/deploy.yml
   git commit -m "Fix GitHub Pages deployment"
   git push origin main
4. In GitHub's Actions tab, wait for Deploy website to GitHub Pages to succeed.
5. Open https://anojaaa.github.io/The-MongolZ-World/.
